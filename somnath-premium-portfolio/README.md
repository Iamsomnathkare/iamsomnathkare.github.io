# Somnath Premium Portfolio Website

A complete, responsive, premium-style personal portfolio website for Somnath Tanaji Kare.

## What is included

- `index.html` - Main portfolio website
- `css/styles.css` - Complete responsive styling with dark/light theme
- `js/script.js` - Theme toggle, mobile menu, and scroll reveal animation
- `assets/profile-avatar.svg` - Custom developer avatar
- `assets/favicon.svg` - Website favicon
- `resume/Somnath_Tanaji_Kare_Resume_Placeholder.txt` - Replace with your actual resume

## How to use

1. Unzip the package.
2. Open `index.html` in any browser.
3. Replace placeholder contact details with your actual email, LinkedIn, GitHub, and resume.
4. Deploy using GitHub Pages, Netlify, Vercel, or any static hosting provider.

## Recommended personal updates before publishing

- Replace `your.email@example.com` with your real email.
- Replace the resume placeholder with your PDF resume and update the link in `index.html`.
- Add your real LinkedIn and GitHub links in the Contact section.
- Add live project links if available.
